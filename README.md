# Эмулятор оболочки UNIX (вариант 22)

## 1. Общее описание

Эмулятор командной строки UNIX-подобной ОС на Python 3.8+ без внешних зависимостей.
Работает в интерактивном режиме (REPL): приглашение содержит имя VFS.

Структура репозитория: `src/` — исходный код, `tests/` — модульные тесты, скрипты `.emu` и
скрипты ОС, `run.sh` / `run.bat` / `Makefile` — запуск.

## 2. Описание функций и настроек

**Приглашение:** `имя_VFS$ ` (на этапе 4 — `имя_VFS:/текущий/каталог$ `).

**Переменные окружения:** `$VAR` и `${VAR}` раскрываются значениями реальной ОС. В
одинарных кавычках не раскрываются, неизвестная переменная — пустая строка. Комментарий
начинается с `#`.

**Команды:** `ls` и `cd` — заглушки, печатают имя и аргументы; `exit [код]` — завершение
работы.

## 3. Сборка и запуск тестов

Сборка не нужна, нужен только Python 3.8+.

```
./run.sh [параметры]        # Linux / macOS
run.bat [параметры]         # Windows
make run                    # через Makefile
```

Модульные тесты:

```
make test
```

Без `make`: `PYTHONPATH=src python3 -m unittest discover -s tests -v` (в Windows: `set
PYTHONPATH=src`, затем `python -m unittest discover -s tests -v`).

Демонстрация этапа: `bash tests/os_scripts/run_stage1.sh` или
`tests\os_scripts\run_stage1.bat`.

## 4. Примеры использования

```
$ ./run.sh
vfs$ ls -l /tmp
ls: аргументы = ['-l', '/tmp']
vfs$ foo
foo: команда не найдена
vfs$ exit
```
